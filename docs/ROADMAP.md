# Research Roadmap

# From Code Repository to Research Infrastructure

---

# Phase 1 — Project definition

## Objectives

* Define the research problem.
* Define the study objective.
* Define research questions.
* Establish the conceptual scope.

## Outputs

* Research questions.
* Paper plan.
* Initial repository architecture.

---

# Phase 2 — Literature analysis

## Objectives

Identify research project management requirements reported in the scientific literature.

## Activities

1. Define databases.
2. Develop search strategies.
3. Execute searches.
4. Remove duplicates.
5. Screen records.
6. Review full texts.
7. Extract relevant information.

## Outputs

* Literature dataset.
* Included study list.
* Requirement extraction dataset.

---

# Phase 3 — Requirement framework

## Objectives

Develop a framework describing research project management requirements.

## Activities

* Thematic analysis.
* Requirement identification.
* Requirement definition.
* Requirement classification.

## Outputs

* Research Management Requirement Framework.

---

# Phase 4 — GitHub capability analysis

## Objectives

Identify GitHub functionalities relevant to research management.

## Activities

Analyse:

* repositories;
* Issues;
* Projects;
* Milestones;
* Discussions;
* Pull Requests;
* branches;
* Actions;
* Releases;
* Markdown documentation.

## Outputs

* GitHub capability catalogue.

---

# Phase 5 — Requirement-feature mapping

## Objectives

Determine which research requirements can be supported by GitHub.

## Outputs

* Requirement-feature mapping matrix.
* Coverage analysis.

---

# Phase 6 — Reference architecture

## Objectives

Develop the GitHub-based research management framework.

## Outputs

* Conceptual architecture.
* Lifecycle model.
* Workflow definitions.

---

# Phase 7 — Reusable template

## Objectives

Develop a reusable GitHub Research Project Template.

## Outputs

* Repository template.
* Documentation templates.
* Issue templates.
* Pull request templates.
* Workflow configuration.

---

# Phase 8 — Case study implementation

## Objectives

Implement the framework in a real research project.

## Activities

* Configure repository.
* Create Project.
* Define Issues.
* Establish documentation.
* Track decisions.
* Manage research outputs.

## Outputs

* Implemented case study.

---

# Phase 9 — Evaluation

## Objectives

Evaluate the framework.

## Evaluation dimensions

* Requirement coverage.
* Traceability.
* Documentation.
* Organization.
* Transparency.
* Usability.

---

# Phase 10 — Analysis

Analyse:

* framework coverage;
* implementation results;
* strengths;
* limitations.

---

# Phase 11 — Manuscript development

Develop:

* Introduction.
* Materials and Methods.
* Results.
* Discussion.
* Conclusions.

---

# Phase 12 — Publication

* Final review.
* Repository release.
* Data and artifact archiving.
* Manuscript submission.
