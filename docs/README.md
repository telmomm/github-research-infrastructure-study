# Documentation

This directory contains the research design, methodological documentation, planning documents, and conceptual framework for the study:

> **From Code Repository to Research Infrastructure: Evaluating GitHub for Managing the Scientific Research Lifecycle**

The purpose of the documentation is to provide a transparent and traceable record of how the research project is designed, developed, implemented, and evaluated.

# Research workflow

```text
Literature analysis
        ↓
Research management requirements
        ↓
GitHub capability analysis
        ↓
Requirement-feature mapping
        ↓
Reference architecture
        ↓
Reusable project template
        ↓
Real-world implementation
        ↓
Evaluation
        ↓
Scientific manuscript
```

The documentation in this directory represents the methodological foundation of the study.

The final scientific article will be developed in the `/manuscript` directory.
